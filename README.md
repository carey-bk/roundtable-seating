# 围坐 · 圆桌排座

一个简单的圆桌座位排序网页，适合家庭聚餐、婚宴和朋友聚会。先输入人员名单，再拖动姓名调整座位，让相邻关系一目了然。

**[在线体验](https://carey-bk.github.io/roundtable-seating/)**

## 功能

- 支持 **4–30 人**，可按序号逐个填写姓名。
- **一键导入名单**：支持空格、中英文逗号、换行或空行分隔，也能解析 `1.爷爷 2.奶奶` 这样的数字编号。
- **实时拖动排序**：从顶部 1 号开始顺时针排列，拖动一人时，其余人员自动顺移。
- 支持鼠标与触屏操作，也可选中座位后用方向键移动；按 Esc 取消本次拖动。
- 可一键恢复录入顺序；人数较多时，座位图支持滚动查看。

## 使用方法

1. 填写姓名，或粘贴名单后点击「导入名单」。
2. 确认人数和姓名，点击「生成圆桌座位图」。
3. 在圆桌上拖动姓名，调整座位顺序。

导入示例：

```text
1.爷爷 2.奶奶
3.爸爸，4.妈妈
5.哥哥，6.姐姐
```

空格会被视为分隔符；含空格的完整姓名可以在导入后手动修改。

**名单和座位顺序仅保留在当前页面中，不会上传或保存到服务器；刷新或关闭页面后会清空。**

## 本地运行与部署

使用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖或构建。下载项目后，直接在浏览器中打开 `index.html` 即可使用。

也可将 `index.html`、`style.css`、`app.js` 上传到 GitHub Pages、Netlify 等静态网站托管平台。
